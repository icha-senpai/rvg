# Horizon Web

Svelte 5, SvelteKit, TypeScript, and vanilla CSS. This static client is shared by
the web/PWA experience and the Tauri desktop shell. Domain state and mutations
belong to SpaceTimeDB.

Install and run commands from the Horizon 2 workspace root, two directories up.
See [the workspace README](../../README.md) for setup, verification, and pending
integrations. Generated bindings are exposed through `#lib/spacetime`.

The initial route and icons are placeholders. Penpot UI and PWA behavior will be
implemented in the foundation vertical slice.
